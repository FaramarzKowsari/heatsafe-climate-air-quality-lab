# Model Governance

Core safety-relevant classifications are deterministic. A language model may explain a completed result but cannot override it. Standard Mode requires no LLM. Local AI via Ollama and provider-neutral BYOK are optional and disabled unless configured.

Every model card must state training data, target, split design, metrics, uncertainty, known failure modes, prohibited uses, and version. Complex models must be compared with persistence and seasonal baselines before any performance claim.
