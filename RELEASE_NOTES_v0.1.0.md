# v0.1.0 — Research Preview

This release establishes the deterministic HeatSafe scientific core, climate and air-quality analytics, a CPU forecasting benchmark, offline synthetic data, API, browser UI, CLI, tests and research-governance metadata.

It is a research preview rather than a stable operational release. Official-source adapters that require credentials or large geospatial workflows remain documented and intentionally deferred from the offline test suite.
