# Roadmap

- **v0.1 — Research Preview:** deterministic tools, offline demo, typed API, core scientific modules, CPU benchmark.
- **v0.2 — Data Connectors:** production-harden NOAA, EPA AQS, EEA, ECCC, ERA5-Land, FIRMS, and Türkiye adapters.
- **v0.3 — Forecast Benchmark:** city-aware datasets, rolling-origin protocol, calibrated neural baseline, documented leaderboard.
- **v0.4 — Regional Validation:** leave-one-city/region-out validation across Europe, North America, and Türkiye.
- **v1.0 — Stable Public Release:** independent scientific review, accessibility audit, hardened deployment, versioned public datasets.
