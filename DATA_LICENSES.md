# Data Licensing Boundary

Software in this repository is Apache-2.0. Original prose and diagrams are CC BY 4.0 unless a file states otherwise. External data retains its original provider license and terms.

The repository contains synthetic demonstrations and tiny user-created examples. It does **not** relicense or silently redistribute third-party datasets. Before operational deployment, review each provider's latest authentication, rate-limit, attribution, redistribution, and commercial-use terms in `data/catalog.yml`.
