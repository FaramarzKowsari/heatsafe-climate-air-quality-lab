# Companion Exercises

1. Build a Home Heat Profile and identify the first observation you would verify.
2. Compare two ventilation hours with the same temperature but different PM2.5.
3. Import a seven-day home log and inspect thermal lag before and after opening windows.
4. Change electricity price and duty-cycle assumptions in the cooling estimator.
5. Run the synthetic HeatAQ benchmark and compare persistence with tree models without assuming the most complex model wins.
