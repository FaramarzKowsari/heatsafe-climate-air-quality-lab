SCIENTIFIC PACK 07

From a frozen input identity to paper-ready results.

The experiment orchestrator runs HeatAQ Nexus from one immutable JSON specification and produces complete model metrics, uncertainty diagnostics, SVG figures, HTML and Markdown reports, provenance manifests, reproduction commands, SHA-256 verification and a candidate release archive.

Read the protocol Open HeatAQ Nexus
ONE COMMAND

Run, report, package and verify

heatsafe-experiment run --spec experiment.json --output artifacts/run --repository-root .

No paid AI API is required. Synthetic, CSV and frozen-snapshot input modes are supported.

OUTPUT CONTRACT

Every publishable artifact in one directory

Immutable specification

The original configuration and a self-contained reproduction specification are preserved.

Canonical input

The exact benchmark table is copied into the bundle and protected with SHA-256.

Complete metrics

All evaluated models remain available; weaker or negative results are not hidden.

Uncertainty figures

Coverage, interval width, event F1 and best-model MAE are exported as inspectable SVG.

Paper-ready reports

Markdown and standalone HTML summarize methods, results, limitations and reproduction commands.

Candidate release

Citation and repository metadata are prepared without automatically minting or claiming a DOI.
