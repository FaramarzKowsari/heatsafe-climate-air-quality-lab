HOW TO GET A BETTER ESTIMATE

Use measured inputs where possible.

  • Check the device label for input watts.
  • Use your actual electricity price, including the correct unit.
  • Use a plug-in energy meter when the equipment allows it.
  • Keep uncertainty wider when duty cycle is unknown.
Core equation:
kWh = kW × hours × days × duty cycle.
Important: this is an educational estimate, not a utility bill forecast or guaranteed saving. Large fixed electrical equipment should be measured only with appropriate professional equipment.
