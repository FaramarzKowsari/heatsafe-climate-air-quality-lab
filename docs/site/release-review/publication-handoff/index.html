Scientific Pack 09

Publication handoff and draft creation

A controlled transition from a verified research archive to GitHub and Zenodo drafts. Publishing remains blocked until a reserved DOI is inserted, checksums are rebuilt and a final human review is completed.

Final metadata Release review

Draft-only controls

GitHub draft

The generated GitHub CLI command uses --draft and requires an explicit CREATE-DRAFT confirmation.

Zenodo draft

The guide opens the official upload form and prepares exact metadata, files, license, keywords, geography and time-basis fields.

No publish command

No script in this pack can publish Zenodo or convert the GitHub draft into a public release.

Proposed publication identity

Tag: epa-pm25-2025-v0.1.0

Title: US EPA AirData San Diego County, California PM2.5 Forecasting Benchmark v0.1.0

Archive: final harmonized release ZIP plus SHA-256 checksums and dataset citation metadata.

Controlled sequence

  1. Verify and stage the final harmonized archive.
  2. Create GitHub and Zenodo drafts only.
  3. Reserve the Zenodo DOI.
  4. Inject the reserved DOI and rebuild the archive.
  5. Publish Zenodo, confirm DOI resolution, then publish GitHub.
