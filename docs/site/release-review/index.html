PUBLICATION GATE

Review first. Publish later.

Verified source

The builder refuses to package an official experiment that does not pass snapshot and experiment verification.

Curated evidence

Canonical input, model metrics, uncertainty outputs, tables, figures and reports are copied into a self-contained release directory.

Release provenance

Official-source identity, selected geography, station, evaluated interval, source ZIP hash and software revision are preserved.

Publication metadata

CITATION.cff, Zenodo deposition metadata, a future GitHub Zenodo template and DataCite metadata are prepared for review.

Integrity

Every non-archive file receives a SHA-256 checksum and the deterministic ZIP can be rebuilt from the reviewed directory.

No automatic DOI

The pipeline never uploads, publishes or claims a DOI. A human review checklist remains mandatory.

Scientific boundary

A reviewed release improves reproducibility and citation readiness. It does not convert station-level forecasting into personal exposure, medical risk, countywide reconstruction or official warning authority.

The final review stage aligns the public release ID, public experiment ID, actual San Diego geography, monitoring station, UTC/local-time basis, Citation File Format, Zenodo and DataCite metadata while preserving the historical source execution identity in provenance.
