HeatSafe / AI Modes
ACCESSIBLE AI ARCHITECTURE

The scientific core does not depend on a language model.

AI is optional, provider-neutral and subordinate to deterministic or statistical outputs.

Mode 0

Standard

No LLM, no AI key and no cloud provider. Best for reproducibility, CI and offline use.

Mode 1

Local AI

A local model explains an existing result. Numeric grounding and input hashing are recorded.

Mode 2

BYOK

An optional provider-compatible endpoint uses a server-side environment secret.

Allowed

Explanation, documentation, retrieval over selected sources and clearly labeled hypothesis generation.

Not allowed

Changing measurements, overriding decisions, inventing citations or claiming medical or regulatory authority.
