WHAT “LIVE” MEANS HERE

Current model data, not an official sensor network.

  • Weather values are model-derived current conditions and forecasts.
  • Air quality is based on CAMS atmospheric-composition forecasts.
  • PM2.5 at a model grid cell may differ from a nearby street or indoor sensor.
  • Smoke context is not automatically diagnosed; use the manual override when trusted local sources report smoke.
  • The manual planner remains available when the network or external API is unavailable.
Privacy: city search sends the search text to the location service. Device location is requested only after you press the button and grant browser permission.
Important: do not use this page as an emergency warning service. Follow official local heat, smoke and air-quality guidance.
