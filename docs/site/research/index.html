RESEARCH PROGRAM

Scientific questions before model spectacle.

HeatSafe prioritizes data identity, strong baselines, temporal and spatial validation, uncertainty, sensitivity analysis and reproducible artifacts.

Forecast reliability

Which models remain calibrated during extreme events and geographic transfer?

Compound events

When do heat, smoke, PM2.5, humidity and hot nights create non-additive risk?

Urban transfer

Which remote-sensing and morphology features generalize to unseen cities?

Indoor response

Can sparse observations estimate thermal lag and recovery robustly?

AI grounding

Can local and cloud models explain results without altering evidence?

Reproducibility

Which artifacts are necessary for independent replication?
