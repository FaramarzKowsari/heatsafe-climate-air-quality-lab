US EPA AirData San Diego County, California PM2.5 Forecasting Benchmark v0.1.0

A reproducible station-level forecasting benchmark derived from the official US EPA AirData 2025 hourly PM2.5 parameter 88101 product.

Open DOI record Open GitHub release

Geography

San Diego County, California, United States

Monitoring station

06-073-1201

Observations

3,998 hourly rows

Version

0.1.0

Evaluated interval

UTC: 2025-07-18T18:00:00+00:00 through 2026-01-01T07:00:00+00:00

California local time: 2025-07-18T11:00:00-07:00 through 2025-12-31T23:00:00-08:00

The UTC endpoint falls on January 1, 2026 because the final local sample is the last hour of December 31, 2025 in California.

Archive contents

The release includes canonical input data, complete model metrics, uncertainty artifacts, tables, SVG figures, HTML and Markdown reports, source provenance, environment metadata, citation records and SHA-256 checksums.
