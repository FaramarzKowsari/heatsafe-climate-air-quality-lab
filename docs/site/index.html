ACCESSIBLE BY DESIGN

Three capability tiers

Tier 0

Standard

Deterministic core, local files, synthetic data, CPU baselines and browser tools. No paid AI API.

Tier 1

Local AI

Optional local language models explain existing outputs without changing decisions or measurements.

Tier 2

BYOK

Optional provider-neutral cloud models and credentialed data connectors using user-managed secrets.
