# Official Dataset and Benchmark Release Protocol

1. Download only through documented provider interfaces or official manual downloads.
2. Preserve the untouched raw artifact.
3. Record retrieval timestamp, request parameters and provider citation.
4. Normalize into documented units without overwriting raw data.
5. Generate a quality report and station-selection record.
6. Create a Dataset Card with semantic versioning.
7. Verify size, SHA-256 and tabular dimensions.
8. Register the card and build a deterministic index.
9. Run the frozen benchmark protocol.
10. Create a Benchmark Release Candidate.
11. Review scientific claims, licenses, privacy and redistribution.
12. Deposit the frozen bundle in an archival repository.
13. Add the assigned DOI to the release card only after deposit.
