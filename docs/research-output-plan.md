# Research Output Plan

## Software releases

Each reviewed release should include a tag, changelog, citation metadata, checksums, environment information and a reproducible command sequence.

## Benchmark datasets

HeatAQ Nexus datasets should be versioned independently from software when their data lineage, license or update cadence differs.

## Experiment bundles

A bundle should contain:

- manifest JSON;
- immutable configuration;
- metrics;
- predictions;
- calibration outputs;
- plots;
- model card;
- data card;
- limitations;
- code revision and dependency versions.

## Technical reports

Reports should distinguish exploratory analyses from confirmatory validation and should link every table or figure to a versioned artifact.

## Software paper readiness

The platform should not be submitted as feature-complete until it has:

- sustained public development;
- external users or contributors;
- comprehensive tests;
- independent replication;
- stable documentation;
- real-data benchmark results;
- versioned releases and archived artifacts.
